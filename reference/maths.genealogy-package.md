# maths.genealogy: Mathematics PhD Genealogy Data and Plotting

Query, extract, and plot genealogical data from The Mathematics
Genealogy Project <https://mathgenealogy.org/>. Data is gathered from
the 'WebSocket' server run by the 'geneagrapher-core' project
<https://github.com/davidalber/geneagrapher-core>.
